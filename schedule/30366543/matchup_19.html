Значения из подобной таблицы используются в таблицах вида Chart, где значения столбцов BC1, BC2, BC3 - среднее значение по столбцу M1. Значения упорядочены в порядке столбцов, то есть лучшая комбинация имеет наибольшее значение M1, при равенстве далее сравниваются значения столбцов T и так далее. Значения столбцов: Teams - комбинация команд для вычисления сочетаемости; M1 - количество игр, получаемых с минус одного слота от расставляемых игроков; T - количество игр, получаемых с достаточного числа слотов; C - количество игр, получаемых с одного слота; M2 - количество игр, получаемых с минус двух слотов; ED - мера различия числа игр по матчапам, вычисляется как Евклидова норма.
